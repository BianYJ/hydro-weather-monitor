Eisk 潮汐数据与新版首页说明
============================

一、新版综合态势
----------------

“水文水位”已经合并到“综合态势”，顶部不再保留单独的“水文水位”入口。

综合态势仅保留：

1. 潮汐站态势
2. 数据接收状态、更新时间、自动刷新
3. 实时时间、阳历日期和农历日期
4. 实时天气
5. 潮汐提示
6. 逐小时降雨
7. 当前预报潮高、下次高潮、下次低潮

天气地址和潮汐站分别使用两个独立搜索框。潮汐时次卡片和逐小时降雨柱形图支持鼠标悬浮信息。

二、潮汐站范围
--------------

本版本从 Eisk 公开站点目录读取潮汐站，本次已接入 491 个站点，覆盖上海、天津、香港、澳门以及沿海各省市。

默认潮汐站：上海市金山嘴。
默认天气地址：上海市金山区附近的“金山”。

三、GitHub Pages 自动同步
-------------------------

压缩包内必须同时上传以下内容：

  index.html
  assets/
  data/
  scripts/
  .github/
  favicon.svg

其中：

  .github/workflows/update-eisk-tides.yml
  scripts/update-eisk-tides.mjs
  data/eisk-tides.json

上传后进入 GitHub 仓库顶部 Actions，选择“更新 Eisk 潮汐数据”，点击 Run workflow，可立即同步一次。以后每天北京时间 00:20 自动更新潮汐站目录及未来三天的高潮、低潮时次。

如果工作流提示没有写入权限：

1. 进入 Settings → Actions → General。
2. 找到 Workflow permissions。
3. 选择 Read and write permissions。
4. 保存并重新运行工作流。

四、数据说明
------------

- 数据来源：https://www.eisk.cn/
- Eisk 页面标注潮汐数据来自国家海洋信息中心。
- 本网站读取公开显示的潮汐站目录、高潮、低潮时间和潮高，不读取页面内部加密曲线。
- 当前预报潮高通过相邻高潮、低潮预报点平滑插值得到，只用于态势展示。
- 天文潮位不包含台风、寒潮、气压和洪水等造成的增减水，不能替代实测水位、风暴潮预警或航行安全资料。
