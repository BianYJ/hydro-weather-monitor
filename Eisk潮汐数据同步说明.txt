Eisk 潮汐数据修正版说明
========================

本版本保留原网站的标题和界面：

- 顶部品牌：澜境监测
- 首页标题：水文气象实时监测平台
- 原有深蓝色驾驶舱布局
- 原有天气、台风、点云、CAD、PDF、船舶和三维模型功能

首页调整内容
------------

1. “水文水位”合并到“综合态势”，顶部不再显示独立入口。
2. 综合态势保留潮汐站态势、数据状态、更新时间、自动刷新、实时时间、农历、实时天气、潮汐提示、逐小时降雨、当前预报潮高、下次高潮和下次低潮。
3. 保留天气地址搜索框，新增潮汐站搜索框。
4. 接入 Eisk 当前目录中的 491 个潮汐站。
5. 下次高潮、下次低潮的时间使用放大字体。
6. 潮汐时次和降雨图表支持鼠标悬浮查看数值。
7. 修复顶部功能切换时的船舶/模型遮罩残留问题。

防止数据丢失
------------

潮汐数据同时保存于：

  data/eisk-tides.json
  assets/eisk-tides-data.js

网页优先读取 data 中的最新数据。如果 data 文件夹没有上传或读取失败，会自动使用 assets 中的内置数据，因此不会再出现全部潮汐数据丢失。

更新 GitHub 时至少必须上传：

  index.html
  assets/

如需每天自动同步，还应上传：

  data/
  scripts/
  .github/

进入 GitHub 的 Actions，运行“更新 Eisk 潮汐数据”，以后每天北京时间 00:20 自动更新 data 和 assets 中的潮汐数据。

数据来源：https://www.eisk.cn/
潮汐为天文预报值，不包含台风、寒潮、气压和洪水造成的增减水，仅供态势参考。
