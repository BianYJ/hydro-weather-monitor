Eisk 潮汐数据接入说明
====================

本版本已将“综合态势”和“水文水位”里的演示水文数据，替换为上海沿海潮汐预报：

1. 默认站点：金山嘴
2. 可切换站点：芦潮港、吴淞、高桥、崇明
3. 显示内容：当前预报潮高、涨落状态、下一高潮、下一低潮、今日潮差、24小时曲线
4. 数据来源：https://www.eisk.cn/
5. Eisk 页面标注：潮汐表数据来自国家海洋信息中心；属于天文潮位预报，不含气象增减水。

GitHub Pages 自动同步
---------------------

压缩包内包含以下自动同步文件：

  .github/workflows/update-eisk-tides.yml
  scripts/update-eisk-tides.mjs
  data/eisk-tides.json

上传到 GitHub 仓库后：

1. 进入仓库顶部 Actions。
2. 左侧选择“更新 Eisk 潮汐数据”。
3. 点击 Run workflow，可立即手动同步一次。
4. 工作流以后每天北京时间 00:20 自动同步前一天、当天和后一天数据。

如果 GitHub 提示工作流无写入权限：

1. 进入 Settings → Actions → General。
2. 找到 Workflow permissions。
3. 选择 Read and write permissions。
4. 保存后重新运行工作流。

注意事项
--------

- GitHub Pages 不能直接在浏览器中跨域读取 Eisk 页面，因此采用 GitHub Actions 读取公开页面并更新 JSON。
- 本版本只读取页面上公开显示的高潮、低潮时间及潮高，不读取或破解页面内部的加密曲线数据。
- 页面中的当前潮高和24小时曲线，是依据相邻高潮/低潮预报点进行平滑插值得到的态势展示值。
- 结果仅供态势参考，不能替代实测水位、风暴潮预警或航行安全资料。
